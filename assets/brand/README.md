# Identité visuelle Cruciverbalis

Le symbole associe un **C construit comme une grille de mots croisés** à une **rose des vents**, pour représenter la recherche, l'exploration et le cheminement dans les mots.

## Assets

- `cruciverbalis-icon.svg` — emblème principal, fond transparent.
- `cruciverbalis-favicon.svg` — variante simplifiée pour les petites tailles.

Les fichiers sont vectoriels, autonomes et ne contiennent aucune image bitmap embarquée.
